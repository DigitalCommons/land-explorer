# Land Information

The Land Information section contains information about drawn or selected markers, lines or polygons in [LandExplorer](https://app.landexplorer.coop).

<figure><img src="../../.gitbook/assets/Screenshot from 2024-04-24 14-56-02.png" alt=""><figcaption></figcaption></figure>

For drawn markers the longitude and latitude position coordinates are displayed.

For drawn lines the length is displayed.

For drawn polygons the perimeter length and area (in hectares and acres) is displayed.

When a land ownership polygon is selected, this is where information about the land ownership is displayed. More information on this functionality can be found in the [Land Ownership](data-layers/land-ownership/) section.
