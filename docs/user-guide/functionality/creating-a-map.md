# Creating a Map

Each time you log into [LandExplorer](https://app.landexplorer.coop) you will see a new, blank map called 'Untitled Map'. This is a blank canvas and you can get started exploring data or drawing on the map.

If you want to save your map for later, type a name where it says 'Untitled Map'. Here you can see we called the map 'My Map'.

To rename your map, just write your updated name as the title of the map. This will rename your existing map, and will not create a duplicate of this map.

<figure><img src="../.gitbook/assets/maptitle.png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Changes are automatically saved when you are connected to the internet. You'll see in green 'Changes Saved' when all changes have been saved to your map. You can see this in the image above.
{% endhint %}

{% hint style="danger" %}
Note that if you don't have an internet connection your changes will be not be saved until you reconnect. You can keep making changes while offline but if you close the LandExplorer tab on your browser while you are offline any changes that you make will be lost.
{% endhint %}
