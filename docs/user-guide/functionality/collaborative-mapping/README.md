# Collaborative Mapping

[LandExplorer](https://app.landexplorer.coop) has a range of features to enable communities and teams to create maps and data layers together. These can be shared between a team within [LandExplorer](https://app.landexplorer.coop) and/or shared publicly.

Shared Maps contain markers, lines and polygons. These can be shared to individuals and across teams. They can be shared in a way that only enables people to have read-only or write access. Learn more in the [Shared Maps](shared-maps.md) section of the user guide.

Shared Data Layers are can also contain markers, line and polygons, which can be toggled on and off like other [data layers](../left-toolbar/data-layers/) within LandExplorer. These can be created by and for a specific group of users and can be made public. You can import data into shared data layers from other sources. Learn more in the [Shared Data Layers](bespoke-data-layers.md) section of the user guide.
